What are you writing?

Works without the computer: everything is kept on this iPad until you export it (the Export button), then import that file in penpal on the computer.

Samples on this iPad

Save the file to Files or AirDrop it to the computer, then in penpal open Handwriting and choose Import from iPad. Importing the same file twice is fine: nothing is added twice.

Settings

Hold a credit card (or anything 85.6 mm wide) against the screen and drag the slider until the blue box is exactly as wide as the card. This makes the writing guides real size.

Write each sample the way you normally would. Small differences between samples are good: penpal mixes them so no two letters look stamped.
